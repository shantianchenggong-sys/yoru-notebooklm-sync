プライバシーポリシー / Privacy policy

最終更新 / Last updated: 2026-10-10

何をするか / What it does

この道具は、持ち主のパソコンにあるメモを読み、持ち主の Google ドライブにある、この道具が作った Google ドキュメントだけを作成・上書きする。

The tool reads notes on the owner's computer and creates or updates only the Google Docs it created in the owner's own Google Drive.

集める情報 / Data collected

ほかの人の情報は集めない。持ち主のデータは、持ち主のパソコンと持ち主の Google アカウントの外へ送らない。広告・分析・第三者への提供はしない。

No data is collected from anyone else. The owner's data is not sent anywhere except the owner's computer and the owner's Google account. No ads, analytics, or sharing with third parties.

Google のデータの使い方 / Use of Google user data

権限は https://www.googleapis.com/auth/drive.file だけ。この道具が作ったファイル以外は読まない・変えない。許可は Google アカウントの「サードパーティのアクセス」からいつでも取り消せる。

The only scope is drive.file. The tool does not read or change any file it did not create. Access can be revoked at any time from the Google Account third-party access page.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
